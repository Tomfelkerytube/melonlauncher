**Welcome to the Unofficial Melon Sandbox Launcher!**
## Installation. (windows)
To start the install, go to the releases tab (https://github.com/Tomfelkerytube/melonlauncher/releases)

And download from the latest release "Game.rar", Which is the required file for this setup.

After that, create an folder in "C:\Users\your_user\" called ".games".

Afterwards, create an folder in "C:\Users\your_user\.games" called "MelonSandboxLauncher" (IMPORTANT STEP!)

and grab the "Game.rar" file and move it into the "C:\Users\your_user\.games\MelonSandboxLauncher".

Download and Install WinRAR to unzip the "Game.rar" file. (No password needed for game.rar).

Afterwards. right-click your mouse on the file "Game.rar" in the "MelonSandboxLauncher" folder.

and click "Extract Here" and after, delete the game.rar file.

and this is the last step. Right-click the "Melon Sandbox Launcher.exe" and press on "Create Shortcut".

and afterwards, Right-click the Shortcut file, and press "Rename" and rename it to "Melon Sandbox" or "Melon Sandbox Launcher"

And copy that shortcut file to your Desktop.

And enjoy our Unofficial Melon Sandbox Launcher.
